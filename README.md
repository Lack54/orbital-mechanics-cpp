## What is this
I recently started playing Kerbal Space Program again, and i found myself wanting to do the calculations for the manuevers i was doing out of curiosity. The purpose of this project is to learn more about orbital mechanics by doing the math programmatically. This tool is designed to be used for Kerbal Space Program although to use custom planets all you need to do is make your own planets in bodies.h. 

### Current Features - 
  * Modular planet switching
  * Semi major axis 
  * Orbital velocity
  * Circularization (Hohmann transfer) delta V cost 
 
### Next Up -
